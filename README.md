# Villager News (client-only)

Client-only rewrite of the Villager News port. Works on any server (vanilla, Paper, Fabric)
because all dialogue is decided on your own client. Needs Fabric, Fabric API, EMF, ETF, ESF.

The 40 MB of sounds/textures are NOT in this repository. The GitHub Action downloads them
from `https://github.com/jrt993/123/releases/download/popa/111.jar` while building.

After upload to GitHub: Actions tab -> "Build client mod" runs automatically (or press "Run workflow").
The finished jar appears under Releases -> "client-latest".
